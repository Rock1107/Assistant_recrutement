Projet : Assistant intelligent pour la gestion des recrutements
Objectif : automatiser l'analyse et le classement des CV selon une offre d'emploi.
Technologies : Python, Streamlit, Pandas, Scikit-learn, PyMuPDF.
Fonctionnalités réalisées : extraction des CV, extraction des compétences, matching CV/offre, calcul du score, visualisation.
État actuel : prototype fonctionnel en cours d'amélioration.
